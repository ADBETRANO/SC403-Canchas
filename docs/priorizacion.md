# Priorización del backlog

**Proyecto:** Golazo – Sistema de alquiler de canchas de fútbol
**Responsable:** Emmanuel Alfaro Aguilar

## Criterio de priorización

Para organizar el backlog del proyecto Golazo, las historias de usuario se clasifican utilizando tres niveles de prioridad: Alta, Media y Baja.

- **Alta:** Funcionalidades esenciales para el funcionamiento del sistema. Su ausencia impediría o afectaría directamente procesos principales como el acceso, la gestión de canchas o la realización de reservas. Se implementan para el Avance 2 (50%).
- **Media:** Funcionalidades importantes que complementan los procesos principales y mejoran la administración o experiencia del usuario, pero que no impiden el funcionamiento básico del sistema.
- **Baja:** Funcionalidades complementarias que aportan valor al sistema, pero pueden desarrollarse después de implementar las funciones principales.

La prioridad de cada historia se determina considerando su importancia para el usuario, su impacto en los procesos principales del sistema y su dependencia con otras funcionalidades.

## HU-16 – Gestionar tipos de cancha
**Como** administrador, **necesito** gestionar los tipos de cancha (Fútbol 5, Fútbol 7 y Fútbol 11), **para** clasificar las canchas y permitir filtrarlas en el catálogo.

- **Prioridad:** Media
- **Pantalla:** P-14 Tipos de cancha
- **Criterios de aceptación:**
  - El administrador puede agregar, editar y desactivar tipos de cancha.
  - La descripción del tipo es obligatoria y no se puede repetir.
  - No se puede desactivar un tipo que tenga canchas activas asociadas.
  - El sistema muestra un mensaje de confirmación al guardar.

---

## HU-17 – Definir horario de apertura y cierre
**Como** administrador, **necesito** definir el horario de apertura y cierre de cada cancha, **para** que los clientes solo puedan reservar dentro de ese horario.

- **Prioridad:** Alta
- **Pantalla:** P-09 Tarifas y horarios
- **Criterios de aceptación:**
  - El administrador puede definir el horario de lunes a viernes y de fines de semana.
  - La hora de cierre debe ser posterior a la hora de apertura.
  - Los cambios se reflejan en la disponibilidad que ve el cliente (HU-11).
  - El sistema muestra un mensaje de confirmación al guardar.

---

## HU-18 – Ver resumen de reservas del día
**Como** administrador, **necesito** ver un resumen del día con el total de reservas confirmadas, pendientes y canceladas, **para** controlar rápidamente la ocupación de las canchas.

- **Prioridad:** Media
- **Pantalla:** P-10 Reservas del día
- **Criterios de aceptación:**
  - El administrador puede seleccionar la fecha a consultar.
  - El sistema muestra el total de reservas por estado.
  - Los totales coinciden con la lista de reservas del día (HU-21).

---

## HU-19 – Registrar tarifa de cancha
**Como** administrador, **necesito** establecer la tarifa de alquiler de una cancha, **para** definir el monto que deberá pagar el cliente por su reserva.

- **Prioridad:** Alta
- **Pantalla:** P-09 Tarifas y horarios
- **Criterios de aceptación:**
  - El administrador debe poder seleccionar la cancha correspondiente.
  - Debe poder registrar una tarifa diurna y una nocturna por hora.
  - La tarifa debe ser un valor numérico mayor a cero.
  - El sistema debe rechazar valores vacíos, negativos o inválidos.
  - La tarifa debe quedar asociada a la cancha correspondiente.
  - El sistema debe confirmar cuando la tarifa sea registrada correctamente.

---

## HU-20 – Modificar tarifa de cancha
**Como** administrador, **necesito** modificar las tarifas de alquiler existentes, **para** mantener actualizados los precios de las canchas.

- **Prioridad:** Media
- **Pantalla:** P-09 Tarifas y horarios
- **Criterios de aceptación:**
  - El administrador debe poder consultar las tarifas registradas.
  - Debe poder seleccionar una tarifa existente para modificarla.
  - El nuevo monto debe ser un valor numérico mayor a cero.
  - El sistema debe rechazar valores vacíos, negativos o inválidos.
  - El nuevo precio debe quedar almacenado correctamente.
  - El sistema debe mostrar un mensaje de confirmación después de actualizar la tarifa.

---

## HU-21 – Consultar reservas
**Como** administrador, **necesito** consultar las reservas realizadas por los clientes, **para** supervisar la ocupación de las canchas.

- **Prioridad:** Media
- **Pantalla:** P-10 Reservas del día
- **Criterios de aceptación:**
  - El administrador debe poder visualizar las reservas registradas.
  - Cada reserva debe mostrar como mínimo la cancha, fecha, horario y cliente asociado.
  - El sistema debe mostrar el estado de cada reserva.
  - El administrador debe poder consultar el detalle de una reserva.
  - La información mostrada debe coincidir con los datos registrados en el sistema.

---

## HU-22 – Consultar reportes
**Como** administrador, **necesito** consultar reportes de las reservas realizadas, **para** analizar el uso de las canchas y apoyar la toma de decisiones.

- **Prioridad:** Baja
- **Pantalla:** P-11 Reportes
- **Criterios de aceptación:**
  - El administrador debe poder acceder al módulo de reportes.
  - El sistema debe mostrar información basada en las reservas registradas.
  - El reporte debe permitir identificar las canchas y fechas correspondientes.
  - La información presentada debe coincidir con los datos almacenados en el sistema.
  - Si no existen datos disponibles, el sistema debe informar al administrador.
  - Los resultados deben mostrarse de forma clara y comprensible.

# HU-16 a HU-22 – Administración y tarifas

**Proyecto:** CanchaYa – Sistema de alquiler de canchas de fútbol  
**Responsable:** Integrante 4

---

## HU-16 – Registrar cancha

**Rol:** Administrador  
**Prioridad:** Alta

**Historia de usuario:**  
Como administrador, necesito registrar nuevas canchas en el sistema, para ponerlas a disposición de los clientes para futuras reservas.

**Criterios de aceptación:**
- El administrador debe poder ingresar el nombre de la cancha.
- Debe poder seleccionar el tipo de cancha, por ejemplo fútbol 5 o fútbol 7.
- Los campos obligatorios deben ser validados antes de guardar.
- El sistema no debe permitir registrar una cancha si faltan datos obligatorios.
- Al registrarse correctamente, el sistema debe mostrar un mensaje de confirmación.

---

## HU-17 – Editar cancha

**Rol:** Administrador  
**Prioridad:** Alta

**Historia de usuario:**  
Como administrador, necesito modificar la información de una cancha registrada, para mantener actualizados sus datos y características.

**Criterios de aceptación:**
- El administrador debe poder seleccionar una cancha existente.
- El sistema debe mostrar la información actual de la cancha.
- El administrador debe poder modificar los datos permitidos.
- Los campos obligatorios deben ser validados antes de guardar los cambios.
- El sistema debe mostrar un mensaje cuando la actualización sea exitosa.

---

## HU-18 – Gestionar disponibilidad de cancha

**Rol:** Administrador  
**Prioridad:** Alta

**Historia de usuario:**  
Como administrador, necesito habilitar o deshabilitar una cancha, para controlar cuáles canchas pueden ser reservadas por los clientes.

**Criterios de aceptación:**
- El administrador debe poder visualizar el estado actual de cada cancha.
- Debe poder cambiar el estado de una cancha entre disponible y no disponible.
- Una cancha no disponible no debe permitir nuevas reservas.
- El cambio de estado debe quedar registrado en el sistema.
- El sistema debe mostrar un mensaje de confirmación después del cambio.

---

## HU-19 – Registrar tarifa de cancha

**Rol:** Administrador  
**Prioridad:** Alta

**Historia de usuario:**  
Como administrador, necesito establecer la tarifa de alquiler de una cancha, para definir el monto que deberá pagar el cliente por su reserva.

**Criterios de aceptación:**
- El administrador debe poder seleccionar la cancha correspondiente.
- Debe poder ingresar el monto de la tarifa.
- La tarifa debe ser un valor numérico mayor a cero.
- El sistema debe rechazar valores vacíos, negativos o inválidos.
- La tarifa debe quedar asociada a la cancha correspondiente.
- El sistema debe confirmar cuando la tarifa sea registrada correctamente.

---

## HU-20 – Modificar tarifa de cancha

**Rol:** Administrador  
**Prioridad:** Alta

**Historia de usuario:**  
Como administrador, necesito modificar las tarifas de alquiler existentes, para mantener actualizados los precios de las canchas.

**Criterios de aceptación:**
- El administrador debe poder consultar las tarifas registradas.
- Debe poder seleccionar una tarifa existente para modificarla.
- El nuevo monto debe ser un valor numérico mayor a cero.
- El sistema debe rechazar valores vacíos, negativos o inválidos.
- El nuevo precio debe quedar almacenado correctamente.
- El sistema debe mostrar un mensaje de confirmación después de actualizar la tarifa.

---

## HU-21 – Gestionar reservas

**Rol:** Administrador  
**Prioridad:** Media

**Historia de usuario:**  
Como administrador, necesito consultar las reservas realizadas por los clientes, para supervisar la ocupación de las canchas.

**Criterios de aceptación:**
- El administrador debe poder visualizar las reservas registradas.
- Cada reserva debe mostrar como mínimo la cancha, fecha, horario y cliente asociado.
- El sistema debe mostrar el estado de cada reserva.
- El administrador debe poder consultar el detalle de una reserva.
- La información mostrada debe coincidir con los datos registrados en el sistema.

---

## HU-22 – Consultar reportes

**Rol:** Administrador  
**Prioridad:** Media

**Historia de usuario:**  
Como administrador, necesito consultar reportes de las reservas realizadas, para analizar el uso de las canchas y apoyar la toma de decisiones.

**Criterios de aceptación:**
- El administrador debe poder acceder al módulo de reportes.
- El sistema debe mostrar información basada en las reservas registradas.
- El reporte debe permitir identificar las canchas y fechas correspondientes.
- La información presentada debe coincidir con los datos almacenados en el sistema.
- Si no existen datos disponibles, el sistema debe informar al administrador.
- Los resultados deben mostrarse de forma clara y comprensible.
